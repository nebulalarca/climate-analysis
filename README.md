readme = """# Climate Change Analysis

Analysis of global and Turkey-specific temperature trends using NASA GISTEMP and Berkeley Earth datasets.

## Data Sources
- NASA GISTEMP — Global surface temperature anomalies (1750–present)
- Berkeley Earth — Land temperature by country (1743–present)
- NOAA — Atmospheric CO2 concentrations (Mauna Loa)

## Key Findings
- Global land surface temperature has increased significantly since the 1900s
- Turkey follows the global warming trend, with a sharp rise after 2000
- Both global and Turkey anomalies show parallel trends since the industrial era

## Libraries Used
- pandas — data manipulation
- matplotlib — visualization
- xarray — NetCDF file processing
- numpy — numerical operations
